# Stride Companion

Static frontend export of the deployed StepWise - AI Step Counter app.

## GitHub Pages

This repository is configured for GitHub Pages. The frontend bundle is hosted as a static site.

The deployed app uses backend routes including /api/steps/today, /api/steps/history, /api/steps/streak, /api/steps/badges, /api/steps/goal, /api/ai/motivate, and /api/ai/chat. GitHub Pages cannot run those server routes, so live step tracking and AI features require the original Replit backend (or a separate backend deployment with the same API contract).
